# Fiscal Frontier Website

A responsive, single-page website for Fiscal Frontier.

## Files
- index.html — website structure and content
- style.css — responsive visual design

## How to use
1. Open `index.html` in a browser to preview it.
2. Replace the placeholder email `hello@fiscalfrontier.in` with your real email.
3. Replace/add your actual research articles in the Insights section.
4. For the newsletter form to collect real subscribers, connect it to an email provider or backend.
5. Upload the files to a static host such as GitHub Pages, Netlify, Vercel, or your own hosting.
